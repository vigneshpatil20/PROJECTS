# PROJECTS-VIBE TUNE

Mood Song is a personalized music recommendation application designed to suggest songs based on the user's current mood, emotions, and personal preferences.

Instead of selecting songs manually from a large music library, users can simply describe how they are feeling through text.

The application takes two primary inputs from the user:

--->Mood Description: Users describe their current mood, emotions, or feelings in natural language.

--->Number of Songs: Users specify how many song recommendations they would like to receive.

Based on these inputs, the application analyzes the user's mood and generates personalized music recommendations.

The main objective is to make music discovery more personal, interactive, and emotionally relevant
